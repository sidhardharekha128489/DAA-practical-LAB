# Practical 11 - Floyd-Warshall Algorithm

## Summary
This practical demonstrates the Floyd-Warshall algorithm for finding the shortest paths between all pairs of vertices in a weighted graph. It works by progressively improving the shortest path distances using intermediate vertices. The algorithm is useful for dense graphs where all-pairs shortest paths are required.

## Conclusion
Floyd-Warshall is an efficient dynamic programming approach for all-pairs shortest path problems. It helps in understanding how path costs can be updated through intermediate nodes. This practical is important for learning graph algorithms and shortest path optimization techniques.
