# Practical 10 - Kruskal's Algorithm

## Summary
This practical demonstrates Kruskal's algorithm for finding the Minimum Spanning Tree (MST) of a connected weighted graph. It uses the union-find data structure to select edges in increasing order of weight while avoiding cycles. The program also shows the total cost of the MST and the time complexity of the algorithm.

## Conclusion
Kruskal's algorithm is an efficient greedy method for solving MST problems in graphs. It is especially useful when the graph is represented by edges and weights. This practical helps in understanding graph optimization, cycle detection, and the importance of greedy decision-making in algorithm design.
