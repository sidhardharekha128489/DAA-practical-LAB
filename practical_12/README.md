# Practical 12 - Travelling Salesman Problem

## Summary
This practical demonstrates the Travelling Salesman Problem (TSP), where the goal is to find the shortest route visiting each city exactly once and returning to the start. It uses a brute-force approach to evaluate all possible routes and choose the minimum cost path. The program helps in understanding combinatorial optimization and route planning.

## Conclusion
The Travelling Salesman Problem is a classic example of an NP-hard problem in graph theory and optimization. It shows how the number of possible routes grows rapidly with the number of cities. This practical helps in understanding the complexity of optimization problems and the need for efficient algorithms.
